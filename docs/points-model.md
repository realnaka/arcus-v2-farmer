# 估分模型：积分奖励的是 OI-time

本文是策略 V2 的**判据来源**：为什么把「持仓时间 × 名义」当主项，为什么把「成交量」
和「轮次」降级。所有数字都标注了来源类型 —— **官方公布** 还是 **社区样本反推**。
反推出来的东西是**量级**，不是公式。

---

## 1. 结论先行

**策略优化的变量和积分奖励的变量不是同一个。**

| 指标 | 谁在用 | 与积分的关系 |
|---|---|---|
| 完成轮次 / 换手 | 价差类策略的 KPI | 几乎无关；高频换手是**负项** |
| 平均 OI（持仓名义） | 积分的主输入 | 线性主项 |
| 平均持仓时长 | 决定 OI 能撑多久 | 间接主项 |
| 加成窗口占比 | 免费乘数 | 乘数 |
| 行为画像 | 是否被判为「churn」 | 一票否决级别的折扣 |

---

## 2. 一阶模型

```
积分 ≈ OI-time × 效率      OI-time = Σ(持仓名义 × 持仓小时)
```

两个自报样本给出一致的一阶关系，效率区间约 **1,000–4,000 分 / $1M 名义 OI 维持一周**：

| 样本 | OI-time | 积分 | 隐含效率 |
|---|---|---|---|
| 样本 A | $20k OI 持有一周 = 0.020 $M-week | 21 | ~1,050 分/$M-week |
| 样本 B | $435k × ~8h = 0.021 $M-week | 132 | ~6,400 分/$M-week |
| 平台整体 | $64.06M × 1 周 = 64.06 $M-week | 250,000（含全部路径） | ≤ 3,903 分/$M-week |

平台上限落在两个锚点之间，说明 **1,000 附近的效率是一般账户的合理期望**；
要跑到 4,000 以上，必须叠加 RWA + 隔夜加成，以及存款/推荐的份额。

**推论**：积分近似与「挂着的名义 × 时间」线性，与轮次、与短持仓的成交量近乎无关。
大成交量低分账号的存在，都能用「他们的 OI-time 低」解释。

---

## 3. 平台级的两个常数

这两条是**唯一能直接用除法算出来**的：

| 口径 | 数值 | 来源 |
|---|---|---|
| 纯成交量均值 | **85.0 分 / $1M** | 250,000 ÷ $2.94B（官方周报） |
| 纯 OI 均值上界 | **3,903 分 / $1M-week** | 250,000 ÷ $64.06M（官方周报） |

官方周报的汇总量（**官方公布**）：每周 **250,000 分**、成交 **$2.94B**、
OI **$64.06M**，其中 RWA **$727.6M**、含隔夜周末 **$258.8M**。

> 注意：官方报的 `$64.06M OI` 与「时间加权 OI」不是同一个口径（多半是结算时点快照），
> 所以不要把 3,903 当硬上限。**方向是确定的：OI 是主项，成交量是次项，churn 是负项。**

## 4. 行为项：成交量解释不到一半

对「本周交易量 vs 分数」做对数回归（n=124，**社区样本反推**）：

```
积分 = 42.7 × (本周 $M)^0.66        R² = 0.44
```

- 成交量放大 **10 倍，分数只放大 4.5 倍**；
- R² 只有 0.44 ⇒ **剩下的一半由行为决定**。

把「实际 ÷ 体积模型预测」叫残差，按行为标签分桶：

| 行为标签 | 残差中位 | 读数 |
|---|---|---|
| 对冲 / delta 中性 | **4.33×** | 效率最高的一类 |
| 有上季历史 | 5.35× | 多是「旧仓位继续吃分」，不是交易量 |
| 持仓 4h 以上 | 2.02× | 长持 |
| 提到 OI | 2.20× | 官方路径 1 |
| RWA / 股票永续 | 1.90× | 官方路径 2 |
| 现货 | 1.49× | |
| 付过手续费 / 市价单 | 1.24× | 真实成交略微加分 |
| 推荐 | 1.84× | 独立路径 |
| **剥头皮 / 快开快平** | **0.20×** | 惩罚约 5 倍 |

负残差尾巴最能说明问题 —— **大成交量、零分**：周成交 $200K–750K 的多个账号
只有预测值的 0.02–0.18×。有公开帖子直接写「**免费 maker 不给分**」。

另一种写法（同一批样本，R² = 0.549）：

```
log10(points) = 1.48 + 0.65 × log10(本周 $M) + flags
```

| 项 | 乘数 |
|---|---|
| 截距（$1M 本周量、无标签） | 30.4 分 |
| 交易量弹性 | +0.65（10× 量 → 4.42× 分） |
| 提到 OI | ×2.29 |
| 有上季历史 | ×4.88 |
| 对冲 / delta 中性 | ×2.98 |
| 持仓 4h+ | ×1.44 |
| RWA / 股票永续 | ×1.33 |
| 付手续费 / 市价单 | ×1.11 |
| 现货 | ×1.11 |
| 推荐 | ×1.14 |

## 5. 分布、门槛与池子

### 5.1 排名曲线

对（名次，分数）做拟合（**社区样本反推**，144 个点）：

```
points = 416,188 × rank^(-1.41)      R² = 0.915
```

按名次分桶取中位数再乘桶宽 ≈ **188,000 分**（rank ≤ 9,999，未含前 9 名）；
补上头部后约 **220,000–250,000**，与官方「每周 250,000」吻合
⇒ **那张榜是单周榜，不是跨周累计。**

## 6. 怎么自己度量

`OI-time` 由成交账本重建净持仓并做时间积分，**未平仓仓位计入**，
按市场取绝对值（多空两条腿都算），加成窗口单独拆出来：

```bash
# 读交易所成交账本，默认最近 7 天
arcus-farmer/.venv/bin/python arcus-farmer/tools/points_report.py \
    --config arcus-farmer/config/mainnet.yaml --days 7

# 指定窗口（用于「改参数前后」的对比）
arcus-farmer/.venv/bin/python arcus-farmer/tools/points_report.py \
    --config arcus-farmer/config/mainnet.yaml --since 2026-10-08T11:11:00+08:00

# 离线：把 /v1/fills 的返回存成 JSON
arcus-farmer/.venv/bin/python arcus-farmer/tools/points_report.py \
    --fills-json state/fills.json --days 3
```

报告里的每一列都对应上面的模型：

| 列 | 对应模型里的 |
|---|---|
| `OI $h`、`avg OI` | OI-time 与它的时间平均 |
| `p50 hold` / `p90 hold` | 行为画像（分钟级 vs 小时级） |
| `bonus` | 加成窗口占比（免费乘数） |
| `pts` | `OI-time($M-week) × 效率带` |
| `turnover` | 次项，只用来对照 |

**已知的度量坑**：

- **卡片上的 Total Volume 是 All time**，不是本周。用「分数 ÷ 卡片量」会把一周的分除以几个季的量，
  会把效率低估约 40%。分析时必须用「本周量」。
- 只统计**已平仓**轮次会漏掉正在持有的核心仓，而那恰恰是 OI 的主体 —— 本工具按持仓积分，
  未平仓仓位计入。
- 由外部工具产生的成交如果没进账本，会留下「幽灵仓位」。读报告时要和交易所实际持仓对照。

## 7. 无法识别的部分与可检验的预测

**这份数据无法识别**：

- 官方四条路径里的 market making（tight / deep / consistent）与 retained deposits，
  在样本里没有可分离的记录；
- RWA 加成与隔夜加成的**绝对倍数**（样本里两者高度共线）；
- 推荐的计价方式（推荐量差 12 倍的两个账号分数几乎相同 ⇒ 不是按推荐量线性给分）；
- 「权重随时间调整」的方向（单周快照不可识别）。

**下一期可以检验的预测**：

1. 池子仍是 250,000：排名曲线积分应再落在 240,000–260,000。
2. 分层仍是 1% / 5% / 20% / 50%，总人数约 9,600（±20%）。
3. 面板法：两周都出现的账号，`Δlog(points)` 对 `Δlog(volume)` 的斜率应显著低于 1；
   且**持仓未变（本周无交易）的账号分数应与上周同量级** —— 这两条能直接分离 OI 项与量项。
4. 若官方公布新一周的 volume / OI / RWA 总量，用第 3 节的除法重算两个常数。

## 8. 对策略的三个含义

1. **delta 中性双倍 OI**：多 $1 + 空 $1 = $2 的 OI，成本是一份保证金 ——
   这就是对冲类样本残差 4.3× 的原因。
2. **杠杆是分数乘数**：同样本金，把名义做大就直接放大分数，风险靠对冲抵消。
3. **网格不是积分工具**：一份资本只能产生一份 OI，还要额外承担方向风险；
   短持仓的循环同时落在被折扣的行为桶里。

数量级换算（gross OI 满持一周）：

| gross OI | @900 | @2,000 | @4,000 | 大致名次 |
|---|---|---|---|---|
| $5k | 5 | 10 | 20 | 1,800–2,600 |
| $20k | 18 | 40 | 80 | 800–1,200 |
| $50k | 45 | 100 | 200 | 350–600 |
| $150k | 135 | 300 | 600 | 100–250 |

**要拿更多分，只有资本，没有别的。** 参数能改善斜率，改变不了量级。
